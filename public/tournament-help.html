How tournaments work

A tournament is a set of rooms with one packet list, roster, scoring format and set of stats. The director runs the director console. Moderators read in MODAQ. Players use the Klaxon buzzer.

The two kinds, and who does what

Teams or shootout

  • Teams: scheduled team games in any number of rooms. Rosters, released packets, live stats, errata and protests.
  • Shootout: everyone plays for themselves. Buzz queue, typed answers, chat, and scores that can carry across packets. Starts with one room. See Shootouts.

You can't change the kind after creating the tournament.

Who's who

  • Director: creates the tournament and runs the console at /t/CODE (CODE is the 5-character tournament code).
  • Moderator (reader): reads and scores one room in MODAQ. Gets in with the room's reader link or an approved account.
  • Co-reader: a second scorer in the same game.
  • Players: join with the room code or player link and buzz.

Before the day

1. Create the tournament

Sign in first. Your account then opens the console on any device. Signed out, only this browser holds the director key. Don't clear its site data.

On Create a tournament, fill in:

  • Name and date. List on Klaxon's public tournament directory shows it on Tournaments.
  • Scoring format: tossup scoring, bonuses, the players' scoresheet, showing categories and question text after reading, and Record every buzz. Turn that last one on before play. Buzzes made while it's off aren't kept.
  • Round packets, roster and default room settings. Optional. You can add them later in the console.

Edit settings in the console changes everything except Teams vs Shootout.

2. Upload packets

Upload MODAQ .json files on Packets & roster. You can select several.

  • File name = round label. Use names like 1.json, 2.json.
  • Convert Word files with the packet parser. It also checks them.
  • New rounds start hidden until you release them.
  • Drag rounds to reorder. The order sets round numbers and which round releases next.
  • Tick tiebreaker to upload spare questions moderators can sub in. Split makes one round per question.

By default, moderators need an approved account to load packets. You can turn that off when you create the tournament.

3. Add the roster

Copy the rows from your registration sheet, header included (Team Name, Player 1, Player 2…). Click Paste or edit roster, paste, edit, then Save roster. A registration .qbj also works.

MODAQ and the player join screen use this roster. Names not on it are listed under Players not on the roster.

4. Make the rooms

On Rooms, enter a name prefix and a number and click Add. Each room has three links:

  • Players (/r/CODE): for the teams.
  • Reader: private, for the moderator.
  • Co-reader: private, for a second scorer.

Copy for spreadsheet copies every room's links as rows. New rooms use the default room settings. Moderators can change their own room's.

5. Line up moderators

Two options:

  • Hand out reader links from the Rooms tab, one per room. If the tournament requires approved accounts, moderators still sign in to load packets.
  • Approve accounts. Send the Moderator invite link (/t/CODE/join) from Moderators & links. Moderators click Request to moderate and you Approve or Deny there. You get an email for each request if your account has one. You can also add someone by email or username. Approved moderators can read in any room from the invite page's Read here buttons.

Players who read on their byes. Send them the bye-reader link (/t/CODE/join?as=bye) or use Add bye reader, then add each round and room they read. They see only those packets. Assigned readers by round shows rounds with nobody assigned. Don't give them a reader link.

6. Links for players

On Moderators & links:

  • Player links: a schedule URL and a Discord invite, shown in every room.
  • Player landing page: one secret link with rooms, codes, stats, schedule and Discord. Share it with teams only.

On the day

Release each round

Moderators only see released rounds. On Packets & roster:

  • Release next packet releases the first hidden round.
  • Tick or untick Visible to release or hide one round.
  • Auto-release when a round finishes releases the next round once every active room has finished the current one.

What moderators do

  1. Open the reader link or Read here. Sign in first if accounts are required.
  2. Pick the released round under Packet and click Start reading.
  3. On Set up the game, choose both teams, tick who plays, and put each connected player on a team. Click Start the game.
  4. Read. Buzzes show in the Klaxon buzz panel. Scores reach the console live.
  5. Save & next game files the game as finished, downloads a backup and returns to setup. Players stay in the room.

If a moderator's laptop dies, the same link on another device resumes the game.

What players do

  • Open the player link or enter the room code on the home page. Pick team and name.
  • Early arrivals see a grey NEXT GAME buzzer until their game starts.
  • The live scoresheet (unless you turned it off) has Protest this question on each played row.
  • Stuck buzzer? Press Buzzer isn't clear.

Keeping in touch

  • Message readers (Rooms tab) sends a note to one moderator or all. Players don't see it. Late moderators still get it.
  • Games in progress (Stats tab) shows each room's score, question and running time.
  • Protests appear under Game Data & Protests. Notify me there sends a browser notification for each.

Errata and tiebreakers

Errata and thrown-out questions from MODAQ show on Game Data & Protests. Tiebreakers used on the Packets tab shows which teams have heard each tiebreaker.

After the games

Game Data & Protests

Game Data & Protests lists every game by round. Click a room to download its .qbj. Each game has two buttons:

  • Edit opens the game in a private MODAQ correction room. Changes save to the stats.
  • Remove leaves the game out of standings and downloads. Restore puts it back.

Import YellowFruit file replaces games matched by round and teams and adds new ones.

Protests

Once the moderator records a protest and the game is final, click Rule… and choose denied, answer accepted or question thrown out. You see the score change before applying. If a question must be played, Apply and open a replay room gives you reader and player links.

Stats and downloads

  • Public stats link (/t/CODE/stats): live standings, individual stats and box scores, no answer lines. klaxonbuzz.com/CODE goes there too.
  • Tournament structure: phases (Prelims, Playoffs) and divisions, as in YellowFruit.
  • Download YellowFruit report (.zip): stats as HTML pages. Download for YellowFruit (Packets tab): a .yft file plus the roster .qbj.
  • Buzzpoints: every scored buzz with answer lines. For you only. Report, CSV, or a quizbowlbuzzpoints.com zip. With record every buzz attempt on, the zip adds klaxon_all_buzz_attempts.json.
  • Temporary share links share stats or buzzpoints for 7 days. Revoke any time.

MASSINGER (pick/ban) tournaments

Before each game, teams take turns. The first team bans. Then each team in turn bans and protects, until each has 3 bans. A 26-tossup packet leaves 20. Banned tossups become the tiebreakers in packet order.

The MASSINGER guide, with screenshots →

Director checklist

  1. Create a team tournament. Tick MASSINGER pick/ban, then pick who picks and the seconds per pick.
  2. Upload packets: over 20 tossups each (26 for all six bans), with each tossup's subcategory after the author in its metadata: <Author, Science - Biology>. The Packets tab checks each round.
  3. Upload the roster.
  4. Add rooms, then send moderators their reader links or the moderator invite link (and approve requests).
  5. Share the player landing page or the room links.
  6. Each round: Release next packet.
  7. After: fix or remove games on Game Data & Protests, then download from Stats.

Moderator checklist

  1. Open your reader link, pick the released round, Start reading.
  2. Choose both teams, tick who plays, and put every connected player on a team. Then Begin pick/ban.
  3. Players pick on their screens. When it's done, Continue to the game.
  4. Read, then Save & next game.

Set up

  1. Create the tournament as a team tournament. Tick MASSINGER pick/ban before each game. Choose who picks (anyone on the team, captains, the moderator, or nobody for random bans) and the seconds per pick (0 for none). Random bans removes 6 tossups at the start with no protects. Both can be changed later, and per game by the moderator.
  2. Check the packets. More than 20 tossups per round (26 uses all six bans). Each tossup needs Category - Subcategory after the author (<Author, Science - Biology>), with at least two different subcategories. Other packets are read in full. The Packets tab flags problems.
  3. Upload the roster (Packets & roster). Moderators choose teams from it. With roster joining on, players pick their team when they join.
  4. Make the rooms and line up moderators as above.

Each game

  1. Release the round. The moderator picks it and clicks Start reading.
  2. Teams. On Set up the game, choose the teams and who plays, put every connected player on a team, and pick captains if captains pick. Set who picks first (coin flip by default), who picks, and the seconds per pick.
  3. Pick/ban. The moderator clicks Begin pick/ban. Players pick on their screens. A timeout makes a random pick. The moderator can undo or edit picks.
  4. Read. Continue to the game starts the game. The pick/ban result stays folded above it.

Afterwards

Stats work as usual. Buzzpoints map each buzz to its question in the full packet. If a packet changed after a game, klaxon_numbering_warnings.json in the zip lists the games to check.

Shootouts

Like a team tournament, except:

  • No teams or roster. Every player is their own team. With Add players to MODAQ as they buzz in on (default), latecomers play from the next question.
  • You set the rules once: scoring, bonuses, carried-over scores, typed answers, buzz withdrawal and player notes. Moderators confirm them.
  • One room to start. With one room, every packet is ready in list order. With two or more, you release rounds as in a team tournament.
  • A smaller console. Packets only, no Stats tab. The room leaderboard is the score, with chat beside the buzzer.

Questions

I opened the console on another computer and can't change anything.

Sign in with the account you created the tournament with. Without an account, only the browser that created it has the director key.

A moderator says there are no packets.

The round isn't released (check Visible on the Packets tab), or they aren't signed in to an approved account. See Moderators & links → Reader accounts.

A moderator shared their own address bar with the players. Can players now moderate?

No. Klaxon strips the private part from the address bar. Only the console gives out reader links.

A team turned up in the wrong room.

They see NEXT GAME and can't buzz. Point them to the right room from the player landing page or the room list.

Somebody's score is wrong in a finished game.

Use Edit on it under Game Data & Protests. Remove drops it from the stats and can be undone.

Can I close a tournament room between rounds?

No. Tournament rooms stay open for the whole tournament.
