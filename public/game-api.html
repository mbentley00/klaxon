Game data API

Read a game as it is played: the score, each team's and player's line, every tossup and bonus, and where in each question the buzzes came. For stream overlays, stats pages and scripts. It reads; it can't change anything.

Getting a key

  • A tournament: the director opens the console, Moderators & links, Game data API, and creates a read-only key. One key covers every room. Moderators of a tournament room can't make one.
  • A room outside a tournament: the moderator opens the room's options (in MODAQ, Buzzer options), Game data API.

Making a new key, or turning the API off, stops the old key at once.

Question text

The key's owner chooses how far question text goes. Both are counted in each room separately, and questions a room hasn't reached are never exposed:

  • Expose question text up until the current question being read in this room (the default): the tossup being read, and its bonus, come without text until the room moves on. Safe for a stream or a public page.
  • Expose question text up to and including the current question being read in this room: the question being read comes with its text and answer. For staff tools only.

Scores, player lines and who buzzed on what come through in both.

Calls

Pass the key as ?key=… or as a header, Authorization: Bearer …. Any site may call these from a browser. Results are at most a second old, so polling once a second is plenty.

GET /api/rooms/ROOM/game?key=KEY
The room's current game. Add &round=3 for another round's game.
GET /api/tournaments/CODE/games?key=KEY
Every room in the tournament, each with its status and current game (or null).

What a game contains

  • round, inProgress, currentQuestion, regulation, tossupsRead, status (playing, overtime, finished…), and source: modaq or scoresheet.
  • teams[]: score, tossupPoints, bonusPoints, bonusesHeard, ppb, and players[] with tuh, answers (count of each value, e.g. {"15": 2, "10": 3, "-5": 1}) and points.
  • questions[], one per tossup read: tossup (question, answer, words), buzzes[] (player, team, value, wordIndex, word, celerity: 1 at the first word, 0 at the last), bonus (team, points, leadin, parts[] with text, answer, points), and score, the score after it.
  • buzzLog[]: every buzzer press in the room, including the ones that lost the race, with order and msAfterFirst.

Games scored on Klaxon's scoresheet have no buzz positions: wordIndex, word and celerity are null for them.
